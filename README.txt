MY PERSONAL WEBSITE
===================

Open it
  Double-click index.html. It opens in your browser. No install needed.

Make it yours
  1. Photo
     Put your picture in the "assets" folder and name it photo.jpg
     (a portrait, taller than wide, looks best).

  2. Text
     Open js/data.js in any editor (Notepad works). Your name, links,
     projects, experience and skills are all in that one file.
     Change the text between the quotes, save, refresh the browser.

Pages
  index.html        Home
  projects.html     Projects
  experience.html   Experience, education and skills

Other files
  css/style.css     Colours and layout
  js/               Behaviour for each page
  assets/           Images

Shortcuts on the site
  1 2 3   switch pages
  T       light / dark theme
